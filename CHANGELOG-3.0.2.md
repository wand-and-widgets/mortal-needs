# Mortal Needs 3.0.2

This update refreshes the icons across Mortal Needs.

- New gothic SVG illustrations for all 14 built-in needs, the module seal, and interface controls.
- A larger gold seal makes the toolbar button easier to recognize.
- Built-in needs now use their new illustrations even when their rules have been customized. This fixes Hunger retaining its old icon in existing worlds.
- Custom images and font icons are preserved in the dock, dialogs, narration, and broadcast views.

Existing characters, values, and consequence rules are retained. Reload Foundry after updating to load the new icons and styles.

Validation: 61 automated tests, plus GM and player checks in Foundry 14.368 with D&D 5e 6.0.5. See the [compatibility notes](README.md#compatibility) for earlier system checks and remaining limits.
